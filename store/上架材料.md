## 一、只有你本人能做的两件事（我无法代办）

这两项是硬门槛。都需要实名身份或证件，只能由你操作。

### 1. 注册并实名认证开发者账号

- 地址：https://open.oppomobile.com → 注册
- **个人开发者可以发布移动应用**（平台权益表：企业 √ / 个人 √），不必注册公司
- 个人认证需要：姓名、身份证号、**本人手持身份证照片**、**由该身份证办理的银行卡号**

### 2. 办理版权证明（软著 或 电子版权证书）

上传页明确要求"上传版权证明资料 → 电子版权证书"。两条路：

| 方式 | 说明 | 周期 |
| --- | --- | --- |
| **电子版权认证**（推荐，快） | 通过中国版权保护中心或平台认可的第三方（如易版权）在线认证，出电子证书 | 加急 1–5 个工作日 |
| **软件著作权登记** | 中国版权保护中心正式登记，权威性最高 | 普通 30–60 天，加急 3–15 天（收费） |

### 敏感权限说明（必填，逐项）

| 权限 | 使用场景说明（填这段） |
| --- | --- |
| `RECORD_AUDIO`（麦克风/录音） | 仅在用户主动点击"语音"按钮时调用系统语音识别，将一次性口述内容转为文字填入输入框，用于生成记录。不点击则不录音，不在后台录音，不保存任何音频文件，也不会上传音频至开发者服务器。用户可拒绝该权限，拒绝后仍可正常使用文字输入及全部其他功能。 |

**「权限说明」页逐字段填法（对应后台表格）**

| 字段 | 填什么 |
| --- | --- |
| 具体权限 `RECORD_AUDIO` 的【高频使用目的】 | `语音输入/录制`（若下拉里另有单独的「语音输入」，优先选它） |
| 具体权限 `RECORD_AUDIO` 的【具体功能】 | **`发送语音信息/语音转文字`** ← 最关键，别选「录制音频」，我们不留音频文件 |
| `RECORD_AUDIO` 的【功能补充说明】 | "仅点击「语音」时申请；不后台录音、不保存音频、不上传音频；拒绝后仍可用文字输入及全部功能。" |
| 具体权限 `BIND_DEVICE_ADMIN` 的【高频使用目的】 | `未使用该项权限` |
| 具体权限 `BIND_DEVICE_ADMIN` 的【功能补充说明】 | "本应用未使用设备管理器功能，安装包内未声明该权限。" |

> `BIND_DEVICE_ADMIN` 是 OPPO 后台的**通用模板行**，不是从我们包里扫出来的。已核实：整包二进制中不存在该字符串（UTF-16 与 ASCII 均无），工程源码中也从未出现。它属于"逐条声明用不用"的清单，照上面填「未使用」即可。
>
> 若该页底部提示"请按提示，补充完整表格中的必填项"，通常是 `具体功能` 列还有行没选，目视检查每一行该列是否都不为空。

## 四、审核容易被拒的四个点与对策

1. **图标与安装包不一致** → 已处理：商店 icon 与 APK 内 `ic_launcher.png` 现在来自同一个直角源文件。
2. **截图含状态栏通知图标** → 已处理：截图由无头浏览器渲染，本就没有状态栏。
3. **隐私政策不完整 / 首次启动未弹隐私提示** → 已处理：`privacy.html` 逐项写明麦克风用途、可拒绝、数据只存本机、无第三方 SDK，并可公开访问；**应用首次启动即弹出隐私说明弹窗**，明确列出麦克风与本地存储用途，提供「不同意」出口（不退出、不索取、仅说明后果），用户点「同意」后才写入同意标记。这是国内商店与隐私合规检测最常见的驳回项，务必保留。
4. **功能过于简单被判"无实际内容"** → 提交时把"软件介绍"里的四项功能写全（上面文案已包含），并说明词典条目数、周报指标，避免被当成空白壳应用。

**隐私合规自检要点（对应 OPPO「隐私安全检测」）**

| 检测项 | 本应用状态 |
| --- | --- |
| 首次启动展示隐私政策并取得同意 | 有，弹窗在应用内、未同意前不写入任何数据 |
| 申请权限前告知用途 | 有，弹窗已列明麦克风用途；真正申请权限只发生在点击「语音」时 |
| 拒绝权限后能否继续使用 | 能，拒绝麦克风仍可文字输入，功能不受限（已在权限说明中写明） |
| 是否强制、频繁索取权限 | 否，不点「语音」永不申请 |
| 隐私政策可访问 | 应用内「关于」与弹窗均可点开，链接为相对路径，APK 内可直接打开 |
| 第三方 SDK / 数据出境 | 无任何 SDK，无数据上传 |

另外两点提醒：

- 类目别选 `生活娱乐 - 互动娱乐`，那类会进额外审核且通过后不可改类目。
- 首次审核 OPPO 一般 3–5 个工作日，被拒会给出具体条款编号，按编号改即可，不要重复提交同一版本。
