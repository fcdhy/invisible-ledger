## 一、只有你本人能做的三件事（我无法代办）

这三项是硬门槛，缺任何一项提交都会被驳回。都需要实名身份、证件或缴费，只能由你操作。

### 1. 注册并实名认证开发者账号

- 地址：https://open.oppomobile.com → 注册
- **个人开发者可以发布移动应用**（平台权益表：企业 √ / 个人 √），不必注册公司
- 个人认证需要：姓名、身份证号、**本人手持身份证照片**、**由该身份证办理的银行卡号**
- 审核时长：人工审核 1–3 个工作日
- 注意：平台**不接受个体工商户**注册

### 2. 办理版权证明（软著 或 电子版权证书）

上传页明确要求"上传版权证明资料 → 电子版权证书"。两条路：

| 方式 | 说明 | 周期 |
| --- | --- | --- |
| **电子版权认证**（推荐，快） | 通过中国版权保护中心或平台认可的第三方（如易版权）在线认证，出电子证书 | 加急 1–5 个工作日 |
| **软件著作权登记** | 中国版权保护中心正式登记，权威性最高 | 普通 30–60 天，加急 3–15 天（收费） |

材料准备（我可以帮你整理）：源程序前后各 30 页、软件说明书、身份证、申请表。**名称务必与商店提交的应用名一致**：`隐形账本`。

### 3. 办理 APP 备案（工信部）

2023 年起国内应用商店强制校验。OPPO 平台内部已把"APP备案"改称 **"APP核准"**。备案通过你购买服务器/域名的接入服务商（阿里云、腾讯云等）提交，需主体信息 + 应用信息 + 包名 + 签名 MD5。

- 没有服务器也能备案：用任一接入服务商走"APP 备案"通道即可
- 备案号拿到后填入商店后台"应用备案号"字段
- 周期通常 5–20 个工作日

> 顺带说明：本应用无服务器、不联网，理论上属于"仅在本地运行的工具"，但商店侧目前按统一口径校验，**没有备案号基本无法过审**，这是现实约束，不是技术问题。

### 软件介绍（详细版，可直接贴）

```
隐形账本是一款帮助家庭成员记录、统计"隐形劳动"的工具类应用，把统筹、情绪、记忆、补救四类不产生收入却持续消耗精力的家庭劳动，量化为可比较的条目、时长与金额。

【主要功能】
1. 隐形劳动词典：内置 4 大类共 56 项隐形劳动，每项标注心理负荷指数（1-5 星）、典型耗时与折合金额，支持搜索、分类筛选与按负荷排序。
2. 一句话转结构化数据：输入或口述一段日常记录，应用自动拆分为若干条隐形任务，输出任务名称、类型、承担者、是否属于隐形劳动、预计耗时与折合金额。
3. 家庭隐形劳动周报：自动汇总本周双方承担时长与金额、统筹与情绪劳动占比、分工分配率、高负荷任务排行与未完成事项，并可一键复制为纯文本。

【使用说明】
1. 首次打开即可使用，无需注册登录。
2. 在"词典"页浏览或搜索隐形劳动条目，点"记一笔"可快速计入台账。
3. 在"记录"页输入文字或点击"语音"口述，点"智能拆解"生成结构化记录。
4. 在"周报"页查看本周统计；右上角可修改折算时薪与称呼。

【特点】
- 全部数据只保存在本机，不上传、不联网、无账号体系
- 不包含广告、不做数据变现、不集成第三方统计
- 支持离线使用，语音输入调用系统语音识别
```

## 四、审核容易被拒的四个点与对策

1. **图标与安装包不一致** → 已处理：商店 icon 与 APK 内 `ic_launcher.png` 现在来自同一个直角源文件。
2. **截图含状态栏通知图标** → 已处理：截图由无头浏览器渲染，本就没有状态栏。
3. **隐私政策不完整** → 已处理：`privacy.html` 逐项写明麦克风用途、可拒绝、数据只存本机、无第三方 SDK，并可公开访问。
4. **功能过于简单被判"无实际内容"** → 提交时把"软件介绍"里的四项功能写全（上面文案已包含），并说明词典条目数、周报指标，避免被当成空白壳应用。

另外两点提醒：

- 类目别选 `生活娱乐 - 互动娱乐`，那类会进额外审核且通过后不可改类目。
- 首次审核 OPPO 一般 3–5 个工作日，被拒会给出具体条款编号，按编号改即可，不要重复提交同一版本。
